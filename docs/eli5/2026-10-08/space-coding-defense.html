01

성장시키고, 행동을 바꾸고, 다시 싸운다.

외계인을 처치해 얻은 에너지로 전력을 늘린다. 전투 사이에는 드론의 코드를 고쳐 다음 상황에 대비한다.

코딩은 전투 전략 강화

같은 드론도 “누구를 먼저 공격할까?”, “언제 스킬을 쓸까?”에 따라 다른 역할을 맡는다.

코드를 작성하지 않아도 가장 가까운 적에게 기본 공격을 한다. 처음부터 복잡한 코드를 요구하지 않는다.

02

“적이 3마리 이상 모이면 범위 스킬을 쓴다.” 조건을 계속 확인하고, 실행된 블록과 공격 효과를 함께 강조한다.

설명용 상태 전환이며 실제 전투 시뮬레이션은 아니다. 원문의 “폭탄 스킬” 예시를 화염 드론의 “화염 폭발”로 통일했다. 주변 범위와 대기 중 행동은 상세 규칙에서 확정한다.

03

5개의 웨이브가 하나의 학습 곡선이 된다.

전투에서 필요를 느끼고, 준비 시간에 코드를 바꾼 뒤, 다음 전투에서 효과를 확인한다. 아래 블록 해금 시점은 단계 설계 제안이다.

  1. W1

    일반 외계인

    소환·배치와 기본 자동 공격에 익숙해진다.

    순차 실행예제 코드 따라 보기
  2. W2

    빠른 외계인

    먼저 막아야 할 적을 발견한다.

    공격 대상 선택빠른 적 우선 탐색
  3. W3

    다수의 외계인

    반복 공격으로 몰려오는 적에 대응한다.

    반복문3번 반복하기
  4. W4

    방어막 외계인

    적의 특성에 따라 스킬을 선택한다.

    조건문방어막이 있다면
  5. W5

    최종 보스

    소환·합성과 코딩 전략을 함께 활용한다.

    복합 알고리즘보스 우선 + 반복 + 조건
전투 → 준비 → 전투

준비 시간에 합성·코딩·테스트·저장. 저장한 코드는 다음 웨이브부터 적용한다. 한 판 5–8분은 목표이며 준비 시간 정책을 포함해 검증한다.

승리5웨이브의 모든 외계인과 최종 보스를 처치한다.

패배외계인이 방어선을 통과할 때마다 기지 체력이 감소하며, 0이 되면 종료한다.

04

전투는 크게 보고, 코딩은 준비 시간에.

텍스트 입력 없이 블록을 끌어 연결한다. 처음에는 완성된 예제를 제공해 일부만 바꿔도 결과를 확인할 수 있게 한다.

위 화면은 정보 배치 와이어프레임이다. 실제 서비스에서는 드론 선택 → 코드 편집 → 테스트 → 저장 → 다음 웨이브 적용으로 이어진다.

05

첫 버전은 ‘내 코드가 전투를 바꾼다’를 검증한다.

랜덤 소환의 기대감, 합성의 성장감, 코딩의 전략적 차이를 싱글플레이 한 판 안에 담는다.

1차 개발 · MVP

  • 게임방우주정거장 내 입장·퇴장, 설명과 시작
  • 전투경로 이동, 자동 공격, 기지 체력
  • 콘텐츠5개 웨이브·최종 보스, 드론 3종
  • 성장에너지 소환, 같은 종류·등급 합성
  • 코딩순차·반복·조건 블록, 드론별 알고리즘
  • 피드백테스트, 실행 블록 강조, 전투 효과 연결
  • 결과승패, 보상, 코딩 활용 결과

2차 개발 · 확장

  • 친구와 2인 협동 디펜스
  • 새 드론·특수 합성·다양한 맵과 보스
  • 변수·함수 등 고급 블록
  • 코딩 전략 저장·불러오기
  • 코딩 미션·업적 시스템

협동과 고급 블록은 기본 전투 및 학습 경험을 검증한 뒤 확장한다.

웨이브·보스 클리어→게임 코인→캐릭터 꾸미기·드론 외형

에너지는 한 판의 소환 자원이고, 코인은 꾸미기 보상이다. 보상은 게임 참여와 미션 수행을 기준으로 설계한다.

재미 검증

소환·합성이 다음 행동으로 이어지는가? 플레이어가 다시 한 판을 선택하는가?

학습 검증

코드 변경 뒤 달라진 공격을 설명할 수 있는가? 실패 후 코드를 고쳐 다시 시험하는가?

흐름 검증

첫 이용자가 예제로 코딩을 시작하는가? 준비 시간을 포함해 5–8분 목표에 도달하는가?

검증 질문은 보완 제안이다. 수치 목표와 통과 기준은 사용자 테스트 후 정한다.

06

상세 규칙과 개발 전 결정할 항목

원문에 있는 핵심 방향은 유지했다. 구현을 위해 추가한 정책은 보완 제안으로 구분한다.

프로젝트 정의 · 배경 · 플레이 흐름
장르랜덤 소환 디펜스 + 블록코딩 교육
플랫폼CODMOS 우주정거장 웹 게임방
사용자초등학생. 세부 학년·읽기 수준은 테스트 대상으로 결정.
세계관외계인이 침입한 우주정거장. 플레이어는 방어 시스템을 관리하는 지휘관으로 드론을 소환하고 프로그래밍한다.
레퍼런스원문 제시: 뽀록마법디펜스. 참고 범위는 랜덤 소환·합성과 전투 화면 구조이며, 별도 레퍼런스 분석은 포함하지 않았다.
  1. 우주정거장 포털로 게임방에 입장해 설명을 확인한다.
  2. 초기 에너지를 받고 랜덤 드론을 소환·배치한다.
  3. 웨이브가 시작되면 자동 전투를 관찰하며 추가 소환·합성을 진행한다.
  4. 웨이브 종료 후 준비 시간에 드론을 선택하고 블록을 수정·테스트·저장한다.
  5. 다음 웨이브에서 적용된 코드와 공격 결과를 확인한다.
  6. 5웨이브의 적과 보스를 처치하면 승리한다. 기지 체력이 0이 되면 패배하고 결과 화면으로 이동한다.
소환 · 합성 · 공격 실행 규칙
  • 소환:에너지를 소비해 화염·냉기·전기 중 랜덤 드론 1개를 생성한다. 지정된 배치 영역에서 사거리 안의 적을 자동 공격한다.
  • 합성:같은 종류·같은 등급 2개 → 같은 종류의 상위 등급 1개. 원문의 예시 및 MVP 기준으로 통일했다. 최대 등급과 등급별 증가량은 미정이다.
  • 기본 행동:코딩하지 않은 드론은 사거리 안에서 가장 가까운 적을 기본 공격한다.
  • 공격 간격:반복 블록을 사용해도 드론의 공격속도와 스킬 재사용 대기시간을 지킨다.
  • 코드 적용:준비 시간에 저장한 드론별 알고리즘을 다음 웨이브부터 실행한다.

구현 정책 제안

  • 보완 제안공격 대상이 없으면 다음 판단까지 기다린다. 대상이 사라지거나 사거리를 벗어나면 다시 찾는다.
  • 보완 제안범위 스킬의 “주변”은 사거리 안의 유효한 적으로 정의한다. 실제 범위와 거리 기준은 밸런스에서 확정한다.
  • 보완 제안스킬 대기 중에는 기본 공격으로 대체한다. 사용할 수 없는 이유를 짧게 표시한다.
  • 보완 제안합성 전 결과와 상속할 코드를 보여준다. 두 코드가 다르면 플레이어가 선택하도록 하며, 코드가 조용히 사라지지 않게 한다.
  • 보완 제안에너지가 부족하거나 배치 공간이 없으면 소환을 막고 이유를 표시한다. 실패한 소환에는 비용을 차감하지 않는다.
블록 구성 · 단계별 학습 · 피드백
단계블록 / 행동확인할 학습 경험
순차 실행적 찾기 → 기본 공격 → 다음 적 찾기명령 순서와 드론 행동이 연결된다.
반복문3번 반복, 계속 반복같은 명령을 반복 실행하며 공격 간격을 지킨다.
조건문적 수, 빠른 적, 방어막 여부에 따른 분기조건이 참인지에 따라 행동이 달라진다.
복합 알고리즘보스 우선 탐색 + 반복 + 조건 + 공격여러 명령을 조합해 전략을 설계한다.
  • 초기 진입:완성된 예제 코드에서 일부 블록만 수정하도록 안내한다. 모든 블록을 처음부터 노출하지 않는다.
  • 입력 방식:텍스트 입력 없이 드래그 앤 드롭으로 연결한다.
  • 실행 피드백:실행된 블록, 선택된 적, 실제 공격을 함께 보여 코드와 결과의 관계를 드러낸다.
  • 보완 제안테스트는 재화를 쓰지 않는 미리보기로 제공하고, 잘못 연결된 블록은 위치와 이유를 표시한다.
  • 보완 제안빈 코드에서는 기본 행동을 유지한다. “계속 반복”은 전투 판단 주기마다 실행하고 한 번에 처리할 명령 수를 제한해 화면 멈춤을 방지한다.
  • 보완 제안블록을 끌기 어려운 사용자에게 선택 후 추가·이동하는 조작을 함께 제공한다. 선택·실행 상태는 색과 테두리·문구를 함께 사용한다.

W1–W5에 연결한 해금 시점은 초안이다. 반복·조건의 세부 교육 순서와 개별 미션은 세부 학년과 사용자 테스트 결과에 맞춰 조정한다.

결과 · 보상 · MVP 완료 기준
  • 결과 화면:승패와 보상, 코딩 활용 결과를 보여준다.
  • 재화 구분:에너지는 처치·웨이브 완료로 획득해 소환에 사용한다. 게임 코인은 웨이브·보스 클리어 보상이며 캐릭터 및 드론 꾸미기에 사용한다.
  • 보상 원칙:코딩 정답 여부보다 참여·미션 수행에 기반한다. 꾸미기 아이템 지급과 구매 연결의 1차 개발 범위는 별도 확정한다.
  • 보완 제안결과에서 스킬 사용 횟수·우선 공격한 적·실행된 조건 등 플레이어가 관찰 가능한 코딩 결과를 짧게 요약한다.

MVP 완료 기준 제안

  1. 입장부터 5웨이브 승리 또는 기지 체력 0 패배까지 한 판을 끝낼 수 있다.
  2. 드론 3종을 소환하고 같은 종류·등급의 드론을 합성할 수 있다.
  3. 순차·반복·조건 코드를 저장하면 다음 웨이브에서 해당 드론의 행동이 달라진다.
  4. 기본 공격과 스킬의 간격·대기시간이 반복문 안에서도 유지된다.
  5. 실행 블록과 전투 효과를 함께 확인하고 결과·보상 화면에 도달할 수 있다.
