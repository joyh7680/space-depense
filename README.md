# CODMOS 우주 코딩 디펜스

기획서 `docs/eli5/2026-10-08/space-coding-defense.html`의 전투를 바탕으로 **1–3웨이브**를 플레이하는 Vue 3 + TypeScript + Phaser 3 게임입니다. 세 웨이브는 같은 전투 밸런스를 사용하며 **로봇별 웨이브 미션**으로 순차 실행·반복문·조건문을 배웁니다. 모든 미션의 성공 효과는 해당 로봇의 기본 자동 공격 활성화입니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```powershell
npm install
npm run dev
```

로컬 주소: http://127.0.0.1:5174

```powershell
npm run typecheck
npm test
npm run build
```

## 플레이

- 방 로딩이 끝나면 **3–2–1 카운트다운 후 WAVE 1 전투가 시작**합니다. 카운트다운 중에는 이동·로봇 조작과 적 생성이 시작되지 않습니다. 시작·일시정지 버튼은 없습니다.
- 대원 이동: **캐릭터를 마우스 또는 터치로 직접 드래그**해서 길 밖의 빈 바닥에 놓습니다. 놓으면 해당 칸에 배치되고 근처 괴물을 자동 공격합니다. 바닥 클릭으로는 이동하지 않으며 괴물 길·벽·로봇이 있는 자리에 놓으면 원래 위치로 돌아갑니다.
- **속성 에너지와 자동 소환**: 일반 몬스터 처치 시 무작위 속성 에너지 1개, 소환 보스 처치 시 무작위 속성 에너지 3개를 얻습니다. 하단 속성 에너지 영역에 보유량을 표시하며, 같은 속성 5개마다 이를 소비하고 해당 로봇을 길·대원·다른 로봇을 피해 빈 바닥에 즉시 랜덤 배치합니다. 출격 버튼이나 모달 카드를 클릭할 필요가 없으며, 자동 배치는 기존 로봇 선택과 코딩 패널을 유지합니다. 새로 배치된 로봇은 매번 현재 웨이브의 미완료 미션으로 시작하며 자신의 문제를 완료할 때까지 공격을 기다립니다. 최대 9기이며 한도에 도달하거나 빈 바닥이 없으면 에너지를 보관하고, 자리가 생기면 자동 배치합니다. 기존 소환 몬스터의 희귀 로봇 보상은 보관 상태로 추가됩니다.
- **보관함과 배치**: 하단 `로봇 출격` 버튼과 속성별 카드의 숫자 배지는 **아직 배치하지 않은 보관 로봇 수량**입니다. 에너지로 자동 배치된 로봇은 배지에 포함하지 않습니다. 버튼을 누르면 미사일·전기·냉각 로봇의 가로 3칸 카드 모달이 열리고, 카드를 클릭하면 희귀 보상으로 획득한 해당 속성의 보관 로봇 1대가 길·대원·다른 로봇을 피해 빈 바닥에 랜덤 배치됩니다. 배치에 성공하면 모달이 닫히고 보관 수량이 1대 줄어들며, 0대인 배지는 사라집니다. 보관 로봇이 없는 카드는 회색으로 비활성화되며 에너지 5개마다 자동 배치된다는 안내를 표시합니다. 최대 9대 한도는 보관·배치 로봇을 합쳐 계산합니다. 모달은 바깥 클릭이나 Escape로 닫습니다.
- **전장 로봇 선택**: 전장에는 각 로봇의 이름·번호와 `공격 대기` 또는 `공격 중`을 표시합니다. 로봇을 클릭하면 오른쪽에 그 로봇의 현재 웨이브 미션이 자동으로 열립니다. 새 로봇마다 독립적인 미완료 문제로 시작하며, 다시 클릭한 로봇의 코딩 초안·완료 상태는 유지합니다. 카드를 통한 배치만으로는 코딩 패널을 열지 않으며, 드래그는 위치만 바꿉니다.
- **블록코딩**: 명령어 블록을 클릭하면 `내 코드`의 첫 빈칸에 바로 추가됩니다. 키보드/터치로 블록을 눌러도 동일하게 추가되며, 모든 칸이 차면 블록을 제거한 뒤 추가하도록 안내합니다. 내 코드 안에서는 블록을 드래그해 빈칸으로 이동하거나 다른 블록과 자리를 바꿀 수 있습니다. 모든 칸을 채우면 정답을 자동으로 확인하고, 잘못된 순서는 오류로 안내합니다. 정답을 맞추면 즉시 해당 로봇의 기본 자동 공격이 활성화되고, 로봇 위치에 `green-light` 애니메이션과 `공격 성공!` 문구가 나타납니다. 각 웨이브 미션의 초안·오류·완료 상태는 로봇별로 보관하며 다른 로봇을 선택하거나 패널을 닫아도 유지됩니다.
- **웨이브별 미션**: WAVE 1은 기본 미션(순차 실행), WAVE 2는 중간 미션(반복문), WAVE 3은 강화 미션(조건문)입니다. 같은 웨이브의 문제 유형은 모든 로봇이 같으며, 공격 명령만 미사일 발사하기·냉각 공격·전기 충격 발사로 다릅니다. 각 로봇의 미션 상태를 따로 보관하며 같은 종류도 초안·오류·완료 상태를 공유하지 않습니다.
- **성공 효과**: 모든 웨이브에서 성공하면 해당 로봇의 기본 자동 공격만 활성화됩니다. 한 종류를 선택해 확정하는 제한이 없으며 미사일·냉각·전기로봇 모두 각자 미션을 수행할 수 있습니다. 공격력 강화나 특수 공격 해금은 없습니다. 매 웨이브에서 새로 획득한 로봇은 현재 웨이브 미션을 풀면 공격을 시작합니다.
- **자동 공격**: 한 번 활성화된 기본 자동 공격은 해당 웨이브 안에서 유지됩니다. 기본 공격 성능은 웨이브나 학습 블록에 따라 바뀌지 않으며 단독 보스도 공격합니다. 다음 웨이브에서는 로봇을 다시 획득하고 새 미션을 완료해야 합니다.
- **다음 웨이브**: WAVE 1·2를 클리어하면 방어 성공 결과창을 1초 보여준 뒤 자동으로 다음 웨이브의 **3–2–1 카운트다운**을 시작합니다. 결과창의 다음 웨이브 버튼으로 카운트다운을 바로 시작할 수도 있습니다. 카운트다운 시작 시 속성 에너지는 모두 0개, 상단 에너지는 초기 값 300으로 되돌아갑니다. 보유·배치된 로봇과 로봇별 코딩 상태를 모두 제거하고 소환 개수도 0대로 초기화합니다. 준비 중에는 전투·적 생성·보스 타이머가 멈춥니다. WAVE 3을 클리어하면 완료 결과창을 유지하고 다시 플레이할 수 있습니다.
- **로봇 배치**: 방 안의 로봇을 직접 드래그해 길 밖의 빈 바닥에 놓습니다. 드래그 중 캐릭터가 포인터를 따라 움직이며 배치 가능한 칸은 청록색, 불가능한 칸은 빨간색으로 표시합니다. 잘못된 위치에 놓거나 화면 밖으로 나가면 원래 자리로 돌아갑니다. 바닥 클릭으로는 재배치하지 않으며 이동에 에너지는 들지 않습니다. 목록과 코딩 패널을 사용하는 동안에도 전투는 계속됩니다.

코딩 패널은 정거장 오른쪽에 여백과 둥근 테두리를 가진 떠 있는 UI로 표시합니다. 패널을 열거나 닫아도 게임 필드의 크기와 위치, 프로필·상단 패널·하단 버튼은 유지됩니다. 폭 520px 이하 휴대폰에서도 게임 화면 위에 패널을 겹쳐 표시하며, 패널 내부만 스크롤됩니다. 승패 후 다시 플레이하면 로봇·에너지·미션을 모두 초기화하고 3–2–1 카운트다운 후 전투를 시작합니다.

## 1웨이브 범위

- 일반 적은 웨이브 1에서 민트색 1번(monster-mint.png), 웨이브 2에서 초록색 2번(monster-green.png), 웨이브 3에서 주황색 3번(monster-orange.png) 외형으로 웨이브 시작부터 보스를 처치할 때까지 1.65초마다 계속 등장합니다. 상단 하트는 정거장 내구도 100. 각 웨이브 시작 100초 후 보스급 몬스터 1마리가 자동으로 등장하며 보스 전투 중에도 일반 적 생성이 이어집니다. 상단 총 적 수는 보스 등장 전 예상 수와 실제 생성 수를 반영하고, 보스 처치 시 최종 생성 수로 확정됩니다. 하단 몬스터 표시는 클릭 기능이 없는 카운트다운이며 속성 에너지 영역은 유지합니다. 일시정지 중에는 일반 적 생성과 카운트다운도 멈춥니다.
- 가로 2줄 길: 왼쪽 입구 → 오른쪽으로 이동 → 아래로 회전 → 왼쪽의 우리 기지. 캐릭터와 로봇은 길 밖의 빈 바닥에서만 이동·배치할 수 있습니다. 빈 배치 칸의 + 표시는 없습니다.
- 살아남은 괴물이 한 마리라도 우리 기지에 도달하면 탈출하며 정거장이 파괴됩니다. 지정한 `game-over/5e04ca1208c8` 에셋의 연기가 기지에서 방 전체로 퍼지고 폭발·균열·화면 흔들림이 이어집니다. 2.4초 붕괴 연출이 끝나면 게임 오버가 표시됩니다. 모든 괴물을 탈출 전에 처치해야 승리합니다.
- 모든 웨이브의 미션은 로봇별로 보관합니다. 패널에는 로봇 번호·기본 자동 공격 상태·각 웨이브 미션 완료 여부가 표시됩니다.
- 기본 공격은 사거리 안에 살아 있는 적이 1마리라도 있으면 실행합니다. 전기는 2회 발사와 연쇄 피해, 냉기는 감속, 미사일은 범위·지속 피해를 줍니다. 반복 발사 중 목표가 죽으면 다른 살아 있는 목표를 찾습니다.
- 속성 충전·소환·배치·선택, 일반 몬스터 처치마다 무작위 속성 에너지 1개와 소환 보스 처치마다 독립적으로 추첨한 속성 에너지 3개, 기존 처치 보상 15·완료 보상 50, 승패와 재시작. 합성 규칙은 컨트롤러에 유지하며 카드 목록에는 별도 합성 버튼을 두지 않습니다.
- 최대 9대 / 길 밖 자유 배치 / 최대 3성 / 기본 공격 간격 0.9초
- 보스를 처치하면 새 일반 몬스터 생성을 멈추고, 남아 있는 몬스터까지 모두 처치하면 승리합니다. 12마리 이후와 보스 전투 중의 연속 생성, 다음 웨이브의 생성 초기화, 속성 에너지 획득·충전·소모를 테스트합니다.

블록 편집은 정해진 순차 실행·반복문·조건문 슬롯을 채우는 프로토타입입니다. W4–W5와 최종 보스, 로그인·영구 저장·실제 코인 지급·LMS 방 포털 연동은 아직 없습니다. 다음 웨이브나 다시 플레이를 시작하면 보스 자동 등장 시간도 초기화됩니다.

## 웨이브별 코딩 미션

| 웨이브 | 미션 | 공통 문제 유형 | 블록 구성 | 성공 효과 |
| --- | --- | --- | --- | --- |
| WAVE 1 | 기본 미션 | 순차 실행 | 목표 찾기 → 로봇별 공격 명령 | 해당 로봇 기본 자동 공격 활성화 |
| WAVE 2 | 중간 미션 | 반복문 | 2번 반복하기 → 로봇별 공격 명령 | 해당 로봇 기본 자동 공격 활성화 |
| WAVE 3 | 강화 미션 | 조건문 | 만약 적이 사거리 안에 있다면 → 로봇별 공격 명령 | 해당 로봇 기본 자동 공격 활성화 |

반복문·조건문은 학습 문제이며 실제 전투 성능을 강화하지 않습니다. 기존 기본 공격(미사일의 범위·화상, 냉각의 감속, 전기의 2회 발사·기본 연쇄)은 웨이브에 관계없이 동일하게 사용합니다.
