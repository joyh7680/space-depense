# CODMOS 우주 코딩 디펜스

기획서 `docs/eli5/2026-10-08/space-coding-defense.html`의 전투를 바탕으로 **1–3웨이브**를 플레이하는 Vue 3 + TypeScript + Phaser 3 게임입니다. 세 웨이브는 같은 전투 밸런스를 사용하며 코딩 문제의 블록 수가 단계별로 늘어납니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```powershell
npm install
npm run dev
```

로컬 주소: http://127.0.0.1:5174

```powershell
npm run typecheck
npm test
npm run build
```

## 플레이

- 방 로딩이 끝나면 **WAVE 1 전투가 즉시 시작**합니다. 시작·일시정지 버튼은 없습니다.
- 대원 이동: **PC는 빈 바닥 마우스 클릭, 태블릿은 터치**로만 이동합니다. 괴물 길 밖에서만 상하좌우로 이동하며 근처 괴물을 자동 공격합니다. 길을 가로질러 이동할 수 없습니다.
- **속성 에너지와 자동 소환**: 기존 일반/소환 몬스터의 무작위 에너지 보상을 유지합니다. 하단 속성 에너지 영역에 보유량을 표시하며, 같은 속성 3개마다 이를 소비하고 해당 로봇을 획득합니다. 획득 즉시 `로봇 소환` 버튼의 보유 수와 모달 카드에 반영되며, 선택하기 전까지 방 안에 캐릭터로 표시되거나 바닥을 차지하지 않습니다. 모달에서 로봇을 선택하면 빈 바닥에 공격 대기 상태로 배치되고, 코딩 미션을 완료하면 공격을 시작합니다. 최대 8기이며 한도를 넘는 에너지는 보관합니다. 기존 소환 몬스터의 희귀 로봇 보상도 같은 보유 상태로 추가됩니다.
- **로봇 선택**: 하단 `로봇 소환` 버튼으로 미사일·전기·냉각 로봇의 가로 3칸 카드 모달을 엽니다. 미소환 카드는 회색으로 비활성화되며, 보유 로봇의 카드를 누르면 모달이 닫히고 방 안에 해당 로봇 캐릭터와 공격 대기 표시가 나타나며 오른쪽 미션·블록코딩 패널이 동시에 열립니다. 같은 속성의 카드로 다시 선택하면 다음 로봇으로 순환하며, 이미 배치된 로봇의 위치와 코딩 초안은 유지합니다. 모달은 바깥 클릭이나 Escape로 닫습니다.
- **블록코딩**: 명령어 블록을 클릭하면 `내 코드`의 첫 빈칸에 바로 추가됩니다. 키보드/터치로 블록을 눌러도 동일하게 추가되며, 모든 칸이 차면 블록을 제거한 뒤 추가하도록 안내합니다. 내 코드 안에서는 블록을 드래그해 빈칸으로 이동하거나 다른 블록과 자리를 바꿀 수 있습니다. `코드 실행`을 누르면 빈칸이나 잘못된 순서는 오류로 안내합니다. 로봇별 초안은 다른 로봇을 선택하거나 패널을 닫아도 유지됩니다.
- **공격 활성화**: 로봇 종류와 관계없이 **WAVE 1은 공격 블록 1개**, **WAVE 2는 사정거리 조건 + 공격 블록 2개**, **WAVE 3은 적의수 변수 + 3마리 이상 조건 + 공격 블록 3개**를 사용합니다. 공격 블록만 로봇의 속성(전기·얼음·미사일)에 맞게 바뀝니다. WAVE 1은 클릭 즉시 공격이 활성화되고 WAVE 2·3은 모든 블록을 순서대로 넣고 `코드 실행`을 누릅니다. 같은 웨이브에서는 완료한 미션이 잠기며, 다른 로봇은 별도로 완료해야 합니다.
- **다음 웨이브**: WAVE 1·2를 클리어하면 결과창의 다음 웨이브 버튼으로 진행합니다. 로봇·배치·에너지는 유지하고 모든 로봇의 코딩 초안과 완료 상태를 초기화해 새 웨이브의 문제를 풉니다. WAVE 3을 클리어하면 다시 플레이할 수 있습니다.
- **로봇 배치**: 방 안의 로봇을 선택한 뒤 길 밖 빈 바닥을 누르거나 드래그해 옮깁니다. 이동에 에너지는 들지 않습니다. 목록과 코딩 패널을 사용하는 동안에도 전투는 계속됩니다.

코딩 패널은 정거장 오른쪽에 여백과 둥근 테두리를 가진 떠 있는 UI로 표시합니다. 패널을 열거나 닫아도 게임 필드의 크기와 위치, 프로필·상단 패널·하단 버튼은 유지됩니다. 폭 520px 이하 휴대폰에서도 게임 화면 위에 패널을 겹쳐 표시하며, 패널 내부만 스크롤됩니다. 승패 후 다시 플레이하면 로봇·에너지·미션을 모두 초기화하고 즉시 전투를 시작합니다.

## 1웨이브 범위

- 일반 적 12마리, monster-mint.png 외형, 상단 하트는 정거장 내구도 100. 게임 시작 60초 후 보스급 몬스터 1마리가 자동으로 등장합니다. 하단 몬스터 표시는 클릭 기능이 없는 카운트다운이며 속성 에너지 영역은 유지합니다. 일시정지 중에는 카운트다운도 멈춥니다.
- 가로 2줄 길: 왼쪽 입구 → 오른쪽으로 이동 → 아래로 회전 → 왼쪽의 우리 기지. 캐릭터와 로봇은 길 밖의 빈 바닥에서만 이동·배치할 수 있습니다. 빈 배치 칸의 + 표시는 없습니다.
- 살아남은 괴물이 한 마리라도 우리 기지에 도달하면 탈출하며 정거장이 파괴됩니다. 지정한 `game-over/5e04ca1208c8` 에셋의 연기가 기지에서 방 전체로 퍼지고 폭발·균열·화면 흔들림이 이어집니다. 2.4초 붕괴 연출이 끝나면 게임 오버가 표시됩니다. 모든 괴물을 탈출 전에 처치해야 승리합니다.
- 로봇 1기당 독립적인 미션을 생성하며 블록 수는 현재 웨이브로 결정합니다.
- 코딩 성공 후 WAVE 1·2에서는 모든 로봇이 사정거리 안의 적 1마리부터 공격하고, WAVE 3에서는 주변 적 3마리 이상일 때 공격합니다. 전기는 연쇄 피해, 냉기는 얼음탄과 감속, 화염은 범위 피해와 지속 피해를 줍니다.
- 속성 충전·소환·배치·선택, 처치마다 속성을 각각 독립적으로 추첨한 에너지 총 3개(예: 전기 2개 + 화염 1개), 기존 처치 보상 15·완료 보상 50, 승패와 재시작. 합성 규칙은 컨트롤러에 유지하며 카드 목록에는 별도 합성 버튼을 두지 않습니다.
- 최대 8대 / 길 밖 자유 배치 / 최대 3성 / 기본 공격 간격 0.9초
- 일반 몬스터 처치 후에도 보스를 기다리고, 보스까지 처치해야 승리하는 전투 규칙과 속성 에너지 획득·충전·소모를 테스트합니다.

블록 편집은 정해진 조건·변수·공격 슬롯을 채우는 프로토타입입니다. W4–W5와 최종 보스, 로그인·영구 저장·실제 코인 지급·LMS 방 포털 연동은 아직 없습니다. 다음 웨이브나 다시 플레이를 시작하면 보스 자동 등장 시간도 초기화됩니다.

## 코드모스 원본 에셋

- 대원: `player/int-front`의 **purple** 스킨. 원본 Spine JSON + atlas + PNG와 Phaser 번들 Spine 3.8 런타임으로 애니메이션을 표시합니다.
- 로봇: 원본 Spine 캐릭터의 volta/cloud/monitorhead 스킨을 화염·냉기·전기로 사용합니다.
- 몬스터: public/codmos-assets-monster/759c20f0e742/monster-mint.png 원본 이미지를 사용합니다.
- 방: 기존 `public/games/space/SPACE_MAP_TILESET.png` 원본 타일. 바닥·배치 표시·사거리·전투 효과는 코드 그래픽입니다.

기존 원본 JSON·atlas·manifest는 수정하지 않았습니다. 복원한 이미지의 출처는 `public/codmos-assets/ART-SOURCES.md`에 기록했습니다. 나머지 제공된 리그 일부는 아직 PNG가 없으며 이 게임에서 로드하지 않습니다.

## 구조

- `src/game/defense-simulation.ts`: 렌더러 없는 전투 규칙과 순차 코드 실행
- `src/game/coding-missions.ts`: 웨이브별 미션, 속성별 공격 블록과 코드 검증
- `src/components/robot-coding-panel.vue`: 우측 미션·블록 작업 영역·실행 결과
- `src/game/wave-one.ts`: 로봇, 배치 칸, 밸런스
- `src/game/defense-scene.ts`: 방, 캐릭터, 몬스터, 입력, 효과
- `src/game/create-game.ts`: Spine 플러그인 로드, 게임 생성과 해제
- `src/components/space-defense-room.vue`: Vue와 게임 연결
- `src/app.vue`, `src/style.css`: 화면 전체 게임 HUD, 로봇 목록, 결과창
- `tests/defense-simulation.test.ts`: 소환·합성·공격·속성·승패·정지 검증
- `tests/coding-missions.test.ts`: 개별 초안·오류·완료 잠금·자동 소환·실제 공격 조건 검증

`createDefenseGame(options)`는 비동기이며 `parent`, `assetBase`, `onState`, `onError`, `onInspect`를 받습니다. 컨트롤러는 `setMode`, `summon`, `selectRobot`, `updateCode`, `runCode`, `merge`, `toggleGrid`, `startWave`, `togglePause`, `reset`, `destroy`를 제공합니다. 컴포넌트를 해제할 때 게임·ResizeObserver·이벤트를 정리합니다.
