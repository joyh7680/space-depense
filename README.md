# CODMOS 우주 코딩 디펜스

기획서 `docs/eli5/2026-10-08/space-coding-defense.html`의 전투를 바탕으로 **1–3웨이브**를 플레이하는 Vue 3 + TypeScript + Phaser 3 게임입니다. 세 웨이브는 같은 전투 밸런스를 사용하며 **로봇별 웨이브 미션**으로 순차 실행·반복문·조건문을 배웁니다. 모든 미션의 성공 효과는 해당 로봇의 기본 자동 공격 활성화입니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```powershell
npm install
npm run dev
```

로컬 주소: http://127.0.0.1:5174

```powershell
npm run typecheck
npm test
npm run build
```

## 플레이

- 방 로딩이 끝나면 **3–2–1 카운트다운 후 WAVE 1 전투가 시작**합니다. 카운트다운 중에는 이동·로봇 조작과 적 생성이 시작되지 않습니다. 시작·일시정지 버튼은 없습니다.
- 대원 이동: **캐릭터를 마우스 또는 터치로 직접 드래그**해서 길 밖의 빈 바닥에 놓습니다. 놓으면 해당 칸에 배치되고 주변 360° 원형 범위 안의 모든 괴물을 동시에 자동 공격합니다. 바닥 클릭으로는 이동하지 않으며 괴물 길·벽·로봇이 있는 자리에 놓으면 원래 위치로 돌아갑니다.
- **속성 에너지와 직접 소환**: 일반 몬스터 처치 시 무작위 속성 에너지 1개, 소환 보스 처치 시 무작위 속성 에너지 3개를 얻습니다. 에너지는 계속 모이며, 원하는 로봇을 선택해 소환할 때만 해당 조합을 차감합니다. 크라이오 볼트는 전기 2개 + 냉기 1개 + 화염 1개(총 4개), 써멀 쇼크는 냉기 2개 + 화염 2개 + 전기 1개(총 5개), 플라즈마는 화염 3개 + 전기 2개 + 냉기 2개(총 7개)입니다. 소환 성공 시 빈 바닥에 랜덤 배치하며, 최대 9대이거나 빈 바닥이 없으면 에너지를 보존합니다. 희귀 로봇 보상은 보관하며 모달에서 먼저 배치할 수 있습니다.
- **로봇 배치 카드와 선택 모달**: 하단 `로봇 배치` 카드를 클릭하면 세 종류의 로봇 선택 모달이 열립니다. 각 로봇 카드의 초록색 배지는 현재 에너지와 보관 로봇을 기준으로 소환 가능한 대수입니다. 하단 총 대수는 공유 에너지를 중복 계산하지 않습니다. 소환 불가능한 카드는 비활성화됩니다. 원형 물음표의 호버·키보드 초점·터치로 로봇별 에너지 조합을 확인할 수 있습니다. 원하는 로봇을 클릭해 소환하면 모달이 닫히며, 바깥 클릭이나 Escape로도 닫습니다. 전장에는 소환 애니메이션과 공격 대기 로봇의 반짝이는 표시를 유지합니다.
- **전장 로봇 선택**: 직접 소환한 로봇은 공격 대기 상태이며 코딩 미션을 완료하기 전에는 공격하지 않습니다. 전장 로봇을 클릭하면 현재 Wave와 실제 배치 순서에 맞는 코딩 문제가 열립니다. 다시 클릭한 로봇의 문제·답안 옵션·초안·완료 상태는 유지하며, 드래그는 위치만 바꿉니다.
- **블록코딩**: 명령어 블록을 클릭하면 `내 코드`의 첫 빈칸에 바로 추가됩니다. 키보드/터치로 블록을 눌러도 동일하게 추가되며, 모든 칸이 차면 블록을 제거한 뒤 추가하도록 안내합니다. 내 코드 안에서는 블록을 드래그해 빈칸으로 이동하거나 다른 블록과 자리를 바꿀 수 있습니다. 모든 칸을 채우면 정답을 자동으로 확인하고, 잘못된 순서는 오류로 안내합니다. 정답을 맞추면 즉시 해당 로봇의 기본 자동 공격이 활성화되고, 로봇 위치에 `공격 성공!` 문구가 나타납니다. 각 웨이브 미션의 초안·오류·완료 상태는 로봇별로 보관하며 다른 로봇을 선택하거나 패널을 닫아도 유지됩니다.
- **웨이브별 미션**: WAVE 1은 순차 실행, WAVE 2는 반복문, WAVE 3은 조건문입니다. 난이도는 현재 Wave와 종류에 관계없이 해당 Wave에서 실제 배치한 순서로 정합니다. 보관 중인 로봇은 배치 순서를 증가시키지 않습니다. 재선택·이동·합성으로 기존 미션이 바뀌지 않으며 합성 후 추가 배치는 다음 순서를 사용합니다. 다음 Wave에서 배치 순서는 1번째부터 다시 시작합니다. 문제·초안·오류·완료 상태는 로봇끼리 공유하지 않습니다.
- **성공 효과**: 모든 웨이브에서 성공하면 해당 로봇의 기본 자동 공격이 활성화됩니다. 크라이오 볼트·써멀 쇼크·플라즈마 모두 각자 미션을 수행할 수 있습니다. 매 웨이브에서 새로 출격한 로봇은 현재 웨이브 미션을 풀면 공격을 시작합니다.
- **최종 로봇 공격**: 기본 1성 크라이오 볼트는 로봇 중심 반경 190 안의 가장 가까운 적에게 30HP 전기 볼트를 발사하고 2초 동안 이동속도를 30% 감소시킵니다. 포신은 적 위치를 향해 360° 회전하고 푸른 스파크는 0.8초 표시합니다. 써멀 쇼크는 타깃 방향으로 길이 370, 폭 40의 냉기(파란색)·화염(주황색) 직선 빔을 발사하며 경로의 모든 적에게 각각 45HP 관통 피해를 줍니다. 빔은 1.2초 표시하고 감속은 적용하지 않습니다. 플라즈마는 0.5초 충전 후 로봇 중심 반경 150의 모든 적에게 각각 90HP 피해를 주고 360° 폭발을 1.3초 표시합니다. 충전 중에는 피해를 주지 않으며 폭발 시점의 적 위치로 판정합니다. 이펙트가 유지되는 동안 같은 공격의 피해가 반복되지 않습니다. 일반 몬스터 기본 체력은 100HP로, 한 번 공격받으면 각각 70·55·10HP가 남습니다. 대원은 반경 150의 360° 원형 범위 안에 있는 모든 적에게 0.8초마다 각각 14HP 피해를 주고, 같은 범위의 청록색 원형 펄스를 표시합니다.
- **자동 공격**: 한 번 활성화된 기본 자동 공격은 해당 웨이브 안에서 유지됩니다. 기본 공격 성능은 웨이브나 학습 블록에 따라 바뀌지 않으며 단독 보스도 공격합니다. 다음 웨이브에서는 로봇을 다시 획득하고 새 미션을 완료해야 합니다.
- **다음 웨이브**: WAVE 1·2를 클리어하면 방어 성공 결과창을 1초 보여준 뒤 자동으로 다음 웨이브의 **3–2–1 카운트다운**을 시작합니다. 결과창의 다음 웨이브 버튼으로 카운트다운을 바로 시작할 수도 있습니다. 카운트다운 시작 시 속성 에너지는 모두 0개, 상단 에너지는 초기 값 300으로 되돌아갑니다. 보유·배치된 로봇과 로봇별 코딩 상태를 모두 제거하고 소환 개수도 0대로 초기화합니다. 준비 중에는 전투와 적 생성이 멈춥니다. WAVE 3을 클리어하면 완료 결과창을 유지하고 다시 플레이할 수 있습니다.
- **로봇 재배치**: 소환한 로봇을 직접 드래그해 길 밖의 빈 바닥으로 옮길 수 있습니다. 배치 가능한 칸은 청록색, 불가능한 칸은 빨간색으로 표시합니다. 잘못된 위치나 화면 밖에 놓으면 원래 자리로 돌아갑니다. 이동에는 에너지가 들지 않으며 코딩 패널을 사용하는 동안에도 전투는 계속됩니다.

코딩 패널은 정거장 오른쪽에 여백과 둥근 테두리를 가진 떠 있는 UI로 표시합니다. 패널을 열거나 닫아도 게임 필드의 크기와 위치, 프로필·상단 패널·하단 버튼은 유지됩니다. 폭 520px 이하 휴대폰에서도 게임 화면 위에 패널을 겹쳐 표시하며, 패널 내부만 스크롤됩니다. 승패 후 다시 플레이하면 로봇·에너지·미션을 모두 초기화하고 3–2–1 카운트다운 후 전투를 시작합니다.

## 1웨이브 범위

- 일반 적은 웨이브 1에서 민트색 1번(monster-mint.png), 웨이브 2에서 초록색 2번(monster-green.png), 웨이브 3에서 주황색 3번(monster-orange.png) 외형으로 웨이브 시작부터 1.65초마다 등장하며, 일반 몬스터는 WAVE 1에서 50마리, WAVE 2에서 70마리, WAVE 3에서 90마리까지 생성됩니다. 상단 하트는 정거장 내구도 100. 각 웨이브의 전투 시작 100초 후 보스가 한 마리 등장합니다. WAVE 1은 1번 민트색, WAVE 2는 2번 주황색, WAVE 3은 3번 초록색 보스를 사용하며 추가 보스는 나오지 않습니다. 일반 적과 보스를 모두 처치하면 클리어됩니다. 상단 총 적 수는 보스 1마리를 포함한 51·71·91마리입니다. 하단에는 해당 웨이브 보스 번호와 등장까지 남은 시간이 표시되며 속성 에너지 영역은 유지합니다. 일시정지 중에는 일반 적 생성과 전투도 멈춥니다.
- 가로 2줄 길: 왼쪽 입구 → 오른쪽으로 이동 → 아래로 회전 → 왼쪽의 우리 기지. 캐릭터와 로봇은 길 밖의 빈 바닥에서만 이동·배치할 수 있습니다. 빈 배치 칸의 + 표시는 없습니다.
- 살아남은 괴물이 한 마리라도 우리 기지에 도달하면 탈출하며 정거장이 파괴됩니다. 지정한 `game-over/5e04ca1208c8` 에셋의 연기가 기지에서 방 전체로 퍼지고 폭발·균열·화면 흔들림이 이어집니다. 2.4초 붕괴 연출이 끝나면 게임 오버가 표시됩니다. 모든 괴물을 탈출 전에 처치해야 승리합니다.
- 모든 웨이브의 문제 내용·답안 옵션·미션 상태는 로봇별로 보관합니다. 패널에는 로봇 번호·기본 자동 공격 상태·각 웨이브 미션 완료 여부가 표시됩니다.
- 기본 공격은 코딩 미션을 완료한 로봇의 사거리 안에 살아 있는 적이 있으면 실행합니다. 크라이오는 가장 가까운 적 한 마리, 써멀은 타깃을 관통해 사거리 끝까지 이어지는 직선 경로, 플라즈마는 로봇 중심 원형 범위를 사용합니다. 크라이오만 둔화를 적용하고 화상·연쇄·목표 중심 폭발은 사용하지 않습니다.
- 속성 에너지 획득·조합 확인·직접 소환·전장 로봇 선택, 일반 몬스터 처치마다 무작위 속성 에너지 1개와 소환 보스 처치마다 독립적으로 추첨한 속성 에너지 3개, 기존 처치 보상 15·완료 보상 50, 승패와 재시작. 합성 규칙은 기존 컨트롤러 API로 유지합니다.
- 최대 9대 / 길 밖 자유 배치 / 최대 3성. 같은 로봇의 이펙트가 끝난 뒤 재탐색·조준하며, 플라즈마는 매 공격 전에 0.5초 충전합니다. 기본 재공격 대기 설정은 크라이오 0.4초·써멀 0.9초·플라즈마 1.2초이며 이펙트 시간보다 짧으면 이펙트 종료까지 기다립니다.
- 일반 몬스터와 출현한 보스를 모두 처치하면 승리합니다. 웨이브별 일반 몬스터 생성 수와 100초 후 웨이브별 보스 1마리 등장과 추가 생성 방지, 다음 웨이브의 생성 초기화, 속성 에너지 획득·충전·소모를 테스트합니다.

블록 편집은 정해진 순차 실행·반복문·조건문 슬롯을 채우는 프로토타입입니다. W4–W5와 최종 보스, 로그인·영구 저장·실제 코인 지급·LMS 방 포털 연동은 아직 없습니다. 다음 웨이브나 다시 플레이를 시작하면 보스 출현 조건도 초기화됩니다.

## 웨이브별 코딩 미션

| 로봇 배치 순서 | WAVE 1 순차 실행 | WAVE 2 반복문 | WAVE 3 조건문 |
| --- | --- | --- | --- |
| 1번째 | 1개 | 2개 | 2개 |
| 2번째 | 2개 | 2개 | 3개 |
| 3번째 | 3개 | 3개 | 3개 |
| 4번째 | 3개 | 4개 | 4개 |
| 5번째 이후 | 3개 | 4개 | 5개 |
| 최대 블록 수 | 3개 | 4개 | 5개 |

제어 블록 자체도 1개로 셉니다. 첫 반복문은 제어 블록과 공격 블록으로 2개, 첫 조건문은 2~3개 범위의 하한인 2개를 사용합니다. 정답 성공 시 해당 로봇의 공격을 활성화하고 미션을 완료합니다.

반복문·조건문은 학습 문제이며 실제 전투 성능을 강화하지 않습니다. 크라이오의 단일 둔화 볼트, 써멀의 직선 관통 빔, 플라즈마의 충전 후 원형 광역 폭발은 웨이브에 관계없이 동일하게 사용합니다. 합성은 공격력만 높이며 사거리와 이펙트·충전 시간은 유지합니다.

- 일반 몬스터: public/codmos-assets/monster/의 monster-mint.png, monster-green.png, monster-orange.png 원본 이미지를 웨이브별로 사용합니다.
- 방: 기존 `public/games/space/SPACE_MAP_TILESET.png` 원본 타일. 바닥·배치 표시·레이저 효과는 코드 그래픽입니다. 상시 공격 영역 원 UI는 표시하지 않으며, 대원의 공격 순간에만 실제 판정 범위와 같은 원형 펄스를 표시합니다.

## 구조

- `src/game/defense-simulation.ts`: 렌더러 없는 전투 규칙과 순차 코드 실행
- `src/game/coding-missions.ts`: 웨이브별 미션, 로봇별 프로그램, 코드 검증과 고정 기본 공격
- `src/components/robot-coding-panel.vue`: 우측 미션·블록 작업 영역·실행 결과
- `src/game/wave-one.ts`: 로봇, 배치 칸, 밸런스
- `src/game/robot-energy.ts`: 로봇별 에너지 조합, 소환 가능 대수와 공유 에너지 계산
- `src/game/defense-scene.ts`: 방, 캐릭터, 몬스터, 입력, 효과
- `src/game/create-game.ts`: Spine 플러그인 로드, 게임 생성과 해제
- `src/components/space-defense-room.vue`: Vue와 게임 연결
- `src/app.vue`, `src/style.css`: 화면 전체 게임 HUD, 로봇 목록, 결과창
- `tests/defense-simulation.test.ts`: 소환·합성·공격·속성·승패·정지 검증
- `tests/coding-missions.test.ts`: 웨이브별 공통 유형·로봇별 다른 문제와 답안 옵션·개별 활성화·로봇 및 미션 초기화·성능 불변·단독 보스 공격 검증

`createDefenseGame(options)`는 비동기이며 `parent`, `assetBase`, `onState`, `onError`, `onInspect(id)`를 받습니다. 시뮬레이션은 처치 보상을 에너지로 계속 누적합니다. `deployRobotKind(kind)`는 보관 로봇이 있으면 먼저 배치하며, 없으면 해당 로봇의 에너지 조합을 검증해 랜덤 배치하고 성공 시에만 에너지를 차감합니다. 전장 로봇 클릭 시 `onInspect(id)`로 코딩 패널을 엽니다. 상태의 `robotCount`는 전체 보유 수량, `storedRobotCount`는 미배치 수량, `deploymentOrder`는 현재 Wave의 실제 배치 순서입니다. 컴포넌트를 해제할 때 게임·ResizeObserver·이벤트를 정리합니다.
