# CODMOS 우주 코딩 디펜스

기획서 `docs/eli5/2026-10-08/space-coding-defense.html`의 전투를 바탕으로 **1–3웨이브**를 플레이하는 Vue 3 + TypeScript + Phaser 3 게임입니다. 세 웨이브는 같은 전투 밸런스를 사용하며 **로봇 종류별 기본 미션 + 웨이브별 강화 미션**으로 공격 전략을 배웁니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```powershell
npm install
npm run dev
```

로컬 주소: http://127.0.0.1:5174

```powershell
npm run typecheck
npm test
npm run build
```

## 플레이

- 방 로딩이 끝나면 **3–2–1 카운트다운 후 WAVE 1 전투가 시작**합니다. 카운트다운 중에는 이동·로봇 조작과 적 생성이 시작되지 않습니다. 시작·일시정지 버튼은 없습니다.
- 대원 이동: **캐릭터를 마우스 또는 터치로 직접 드래그**해서 길 밖의 빈 바닥에 놓습니다. 놓으면 해당 칸에 배치되고 근처 괴물을 자동 공격합니다. 바닥 클릭으로는 이동하지 않으며 괴물 길·벽·로봇이 있는 자리에 놓으면 원래 위치로 돌아갑니다.
- **속성 에너지와 자동 소환**: 일반 몬스터 처치 시 무작위 속성 에너지 1개, 소환 보스 처치 시 무작위 속성 에너지 3개를 얻습니다. 하단 속성 에너지 영역에 보유량을 표시하며, 같은 속성 3개마다 이를 소비하고 해당 로봇을 획득합니다. 획득 즉시 `로봇 소환` 버튼의 보유 수와 모달 카드에 반영되며, 선택하기 전까지 방 안에 캐릭터로 표시되거나 바닥을 차지하지 않습니다. 모달에서 로봇을 선택하면 빈 바닥에 배치됩니다. 해당 종류의 기본 미션을 완료한 상태라면 코딩 없이 바로 공격하고, 아직 완료하지 않았다면 공격을 기다립니다. 최대 8기이며 한도를 넘는 에너지는 보관합니다. 기존 소환 몬스터의 희귀 로봇 보상도 같은 보유 상태로 추가됩니다.
- **로봇 선택**: 하단 `로봇 소환` 버튼으로 미사일·전기·냉각 로봇의 가로 3칸 카드 모달을 엽니다. 미소환 카드는 회색으로 비활성화되며, 보유 로봇의 카드를 누르면 모달이 닫히고 방 안에 해당 로봇 캐릭터와 자동 공격 상태가 나타나며 오른쪽 미션·블록코딩 패널이 동시에 열립니다. 같은 속성의 카드로 다시 선택하면 다음 로봇으로 순환하며, 이미 배치된 로봇의 위치와 코딩 초안은 유지합니다. 모달은 바깥 클릭이나 Escape로 닫습니다.
- **블록코딩**: 명령어 블록을 클릭하면 `내 코드`의 첫 빈칸에 바로 추가됩니다. 키보드/터치로 블록을 눌러도 동일하게 추가되며, 모든 칸이 차면 블록을 제거한 뒤 추가하도록 안내합니다. 내 코드 안에서는 블록을 드래그해 빈칸으로 이동하거나 다른 블록과 자리를 바꿀 수 있습니다. `코드 실행`을 누르면 빈칸이나 잘못된 순서는 오류로 안내합니다. 초안·오류·완료 상태는 종류별로 공유하며 다른 종류를 선택하거나 패널을 닫아도 유지됩니다. 모든 미션은 블록을 연결한 뒤 명시적으로 코드 실행을 눌러 완료합니다.
- **기본 미션**: 미사일로봇은 `목표 찾기 → 미사일 발사하기`, 냉각로봇은 `만약 적이 사거리 안에 있다면 → 냉각 공격`, 전기로봇은 `2번 반복하기 → 전기 충격 발사`를 사용합니다. 종류별 최초 1회 완료하면 같은 종류의 모든 로봇과 추가 소환 로봇의 자동 공격을 활성화합니다. 2·3웨이브에서 처음 획득한 종류도 기본 미션을 먼저 풀 수 있습니다.
- **웨이브 강화**: WAVE 2는 조건문, WAVE 3은 변수·조건·특수 공격·아니라면·기본 공격 블록으로 강화합니다. 보유한 종류 중 하나를 선택해 코드를 작성하며, 성공 시 해당 웨이브의 강화 종류를 확정합니다. 성공 전에는 다른 종류로 바꿔 풀 수 있고, 성공 후에는 그 웨이브에서 다른 종류를 강화할 수 없습니다. WAVE 2와 3에서 서로 다른 종류를 선택해도 됩니다. 같은 종류의 기존·추가 로봇 전체가 효과를 공유합니다.
- **공격 유지**: 기본 공격 활성화와 강화 미션 완료를 별도로 관리합니다. 강화 코딩 중이거나 코드가 실패해도 기본 공격과 재사용 대기 시간은 유지됩니다. 강화 조건이 맞지 않으면 기본 공격을 실행하며 보스 한 마리도 정상적으로 대상으로 찾습니다. 같은 종류의 WAVE 3 강화는 WAVE 2 전략을 대신하고, WAVE 2 완료 기록은 보관합니다.
- **다음 웨이브**: WAVE 1·2를 클리어하면 결과창의 다음 웨이브 버튼으로 진행합니다. 로봇·배치·에너지·기본 코딩·강화 완료 상태와 초안을 유지합니다. 새로운 웨이브의 강화 미션만 열리며 기존 자동 공격과 이전 강화 효과는 계속됩니다. WAVE 3을 클리어하면 다시 플레이할 수 있습니다.
- **로봇 배치**: 방 안의 로봇을 직접 드래그해 길 밖의 빈 바닥에 놓습니다. 드래그 중 캐릭터가 포인터를 따라 움직이며 배치 가능한 칸은 청록색, 불가능한 칸은 빨간색으로 표시합니다. 잘못된 위치에 놓거나 화면 밖으로 나가면 원래 자리로 돌아갑니다. 바닥 클릭으로는 재배치하지 않으며 이동에 에너지는 들지 않습니다. 목록과 코딩 패널을 사용하는 동안에도 전투는 계속됩니다.

코딩 패널은 정거장 오른쪽에 여백과 둥근 테두리를 가진 떠 있는 UI로 표시합니다. 패널을 열거나 닫아도 게임 필드의 크기와 위치, 프로필·상단 패널·하단 버튼은 유지됩니다. 폭 520px 이하 휴대폰에서도 게임 화면 위에 패널을 겹쳐 표시하며, 패널 내부만 스크롤됩니다. 승패 후 다시 플레이하면 로봇·에너지·미션을 모두 초기화하고 3–2–1 카운트다운 후 전투를 시작합니다.

## 1웨이브 범위

- 일반 적은 웨이브 1에서 민트색 1번(monster-mint.png), 웨이브 2에서 초록색 2번(monster-green.png), 웨이브 3에서 주황색 3번(monster-orange.png) 외형으로 웨이브 시작부터 보스를 처치할 때까지 1.65초마다 계속 등장합니다. 상단 하트는 정거장 내구도 100. 각 웨이브 시작 100초 후 보스급 몬스터 1마리가 자동으로 등장하며 보스 전투 중에도 일반 적 생성이 이어집니다. 상단 총 적 수는 보스 등장 전 예상 수와 실제 생성 수를 반영하고, 보스 처치 시 최종 생성 수로 확정됩니다. 하단 몬스터 표시는 클릭 기능이 없는 카운트다운이며 속성 에너지 영역은 유지합니다. 일시정지 중에는 일반 적 생성과 카운트다운도 멈춥니다.
- 가로 2줄 길: 왼쪽 입구 → 오른쪽으로 이동 → 아래로 회전 → 왼쪽의 우리 기지. 캐릭터와 로봇은 길 밖의 빈 바닥에서만 이동·배치할 수 있습니다. 빈 배치 칸의 + 표시는 없습니다.
- 살아남은 괴물이 한 마리라도 우리 기지에 도달하면 탈출하며 정거장이 파괴됩니다. 지정한 `game-over/5e04ca1208c8` 에셋의 연기가 기지에서 방 전체로 퍼지고 폭발·균열·화면 흔들림이 이어집니다. 2.4초 붕괴 연출이 끝나면 게임 오버가 표시됩니다. 모든 괴물을 탈출 전에 처치해야 승리합니다.
- 로봇 종류별로 기본 미션과 WAVE 2·3 강화 미션의 프로그램을 각각 보관합니다. 패널에는 기본 완료·각 웨이브 강화 여부와 이번 웨이브에 강화한 종류가 표시됩니다.
- 기본 공격은 사거리 안에 살아 있는 적이 1마리라도 있으면 실행합니다. 전기는 2회 발사와 연쇄 피해, 냉기는 감속, 미사일은 범위·지속 피해를 줍니다. 반복 발사 중 목표가 죽으면 다른 살아 있는 목표를 찾습니다.
- 속성 충전·소환·배치·선택, 일반 몬스터 처치마다 무작위 속성 에너지 1개와 소환 보스 처치마다 독립적으로 추첨한 속성 에너지 3개, 기존 처치 보상 15·완료 보상 50, 승패와 재시작. 합성 규칙은 컨트롤러에 유지하며 카드 목록에는 별도 합성 버튼을 두지 않습니다.
- 최대 8대 / 길 밖 자유 배치 / 최대 3성 / 기본 공격 간격 0.9초
- 보스를 처치하면 새 일반 몬스터 생성을 멈추고, 남아 있는 몬스터까지 모두 처치하면 승리합니다. 12마리 이후와 보스 전투 중의 연속 생성, 다음 웨이브의 생성 초기화, 속성 에너지 획득·충전·소모를 테스트합니다.

블록 편집은 정해진 조건·변수·공격 슬롯을 채우는 프로토타입입니다. W4–W5와 최종 보스, 로그인·영구 저장·실제 코인 지급·LMS 방 포털 연동은 아직 없습니다. 다음 웨이브나 다시 플레이를 시작하면 보스 자동 등장 시간도 초기화됩니다.

## 종류별 강화 효과

| 종류 | WAVE 2 · 조건문 | WAVE 3 · 변수와 조건 분기 |
| --- | --- | --- |
| 미사일 | 주변 적 ≥ 2: 피해 1.35배, 폭발 반경 2.4칸, 화상 계수 30% | 목표체력 ≥ 100: 피해 2배, 아니라면 기본 미사일 |
| 냉각 | 목표가 냉각되지 않음: 피해 1.15배, 주변 2.4칸을 3초간 속도 35%로 냉각 | 사거리 안의 적의수 ≥ 3: 전체 피해 1.4배, 4초간 속도 25%로 냉각, 아니라면 기본 냉각 |
| 전기 | 주변 적 ≥ 2: 2회 발사, 연쇄 대상 최대 2마리, 연쇄 피해 75% | 사거리 안의 적의수 ≥ 2: 피해 1.25배로 3회 발사, 다른 모든 적에게 75% 연쇄 피해, 아니라면 기본 2회 발사 |

변수·강화 조건은 공격 주기마다 현재 살아 있는 사거리 안의 적을 기준으로 갱신합니다. 조건이 거짓이어도 기본 공격은 실행합니다.

- 대원: `player/int-front`의 **purple** 스킨. 원본 Spine JSON + atlas + PNG와 Phaser 번들 Spine 3.8 런타임으로 애니메이션을 표시합니다.
- 로봇: 원본 Spine 캐릭터의 volta/cloud/monitorhead 스킨을 화염·냉기·전기로 사용합니다.
- 일반 몬스터: public/codmos-assets/monster/의 monster-mint.png, monster-green.png, monster-orange.png 원본 이미지를 웨이브별로 사용합니다.
- 방: 기존 `public/games/space/SPACE_MAP_TILESET.png` 원본 타일. 바닥·배치 표시·사거리·전투 효과는 코드 그래픽입니다.

원본 JSON·atlas의 내용은 유지합니다. 몬스터 에셋은 `public/codmos-assets/monster/`에 모으고, 폴더 정리 중 누락된 Spine PNG 3개를 Git 원본에서 복구했습니다. 이미지 출처는 `public/codmos-assets/ART-SOURCES.md`, 파일과 해시는 해당 폴더의 manifest에 기록했습니다. 나머지 제공된 리그 일부는 아직 PNG가 없으며 이 게임에서 로드하지 않습니다.

## 구조

- `src/game/defense-simulation.ts`: 렌더러 없는 전투 규칙과 순차 코드 실행
- `src/game/coding-missions.ts`: 종류별 기본·강화 미션, 공유 프로그램, 코드 검증과 공격 전략 평가
- `src/components/robot-coding-panel.vue`: 우측 미션·블록 작업 영역·실행 결과
- `src/game/wave-one.ts`: 로봇, 배치 칸, 밸런스
- `src/game/defense-scene.ts`: 방, 캐릭터, 몬스터, 입력, 효과
- `src/game/create-game.ts`: Spine 플러그인 로드, 게임 생성과 해제
- `src/components/space-defense-room.vue`: Vue와 게임 연결
- `src/app.vue`, `src/style.css`: 화면 전체 게임 HUD, 로봇 목록, 결과창
- `tests/defense-simulation.test.ts`: 소환·합성·공격·속성·승패·정지 검증
- `tests/coding-missions.test.ts`: 종류별 공유·완료 유지·웨이브 강화 선택·실제 피해와 감속·조건 분기·단독 보스 공격 검증

`createDefenseGame(options)`는 비동기이며 `parent`, `assetBase`, `onState`, `onError`, `onInspect`를 받습니다. 컨트롤러는 `setMode`, `summon`, `selectRobot`, `updateCode`, `runCode`, `merge`, `toggleGrid`, `startWave`, `togglePause`, `reset`, `destroy`를 제공합니다. 컴포넌트를 해제할 때 게임·ResizeObserver·이벤트를 정리합니다.
